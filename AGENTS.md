# VehicleSoundSynth V6 Repository Instructions

- Target Max 8.6.5 using built-in objects only.
- Treat `main.maxpat` as the DSP-free launcher and sole common control surface. The runnable adapters are `VehicleSoundSynth-{EV,V10,V12,IONIQ6N,Ferrari}.maxpat`; open only one at a time. Common lifecycle/input/Mix/EQ/Sound Design wiring is materialized from one generator topology into `patchers/profile_runtime_host_{ev,v10,v12,ioniq6n,ferrari}.maxpat`, while profile patchers contain only profile-specific modes. Their public audio seams are `patchers/vehicle_engine_{ev,v10,v12,ioniq6n,ferrari}~.maxpat`.
- Regenerate patchers/Gen/presets with `python3 tools/build_project.py`; process curated media with `python3 tools/process_assets.py`. Do not hand-edit generated `.maxpat`, `.gendsp`, or `.wav` files. Seed-once user-owned BEAP exceptions are listed in `.codex/REPO_GUIDE.md` and must never be overwritten after creation.
- Run `python3 -m unittest discover -s tests -v` after changes.
- After generator or project-schema changes, open `VehicleSoundSynth-V6.maxproj` in Max 8.6.5 and check the Max log for project-category, missing-object, Gen outlet, and patchcord errors; JSON-only tests are not a runtime smoke test.
- Keep DSP muted on load and protect stereo output against peaks.
- Keep the low-frequency system lifecycle-gated and high-passed near 28 Hz. Center deep bass after the cabin IR with the 120 Hz crossover; stereo phase shaping and early reflections belong only above that crossover.
- Never commit or sync `media/local/` or `/Users/saintpeter/Desktop/Ferrari.wav`. Ferrari continuous-audio derivatives are analysis-only and must never be loaded by a runtime; V10/V12 idle, acceleration, deceleration, and shift recovery must remain procedural. The only optional Ferrari-derived runtime asset is the V10 realistic-start one-shot generated by `tools/prepare_local_reference.py`. Processing must be deterministic and hash-reported, V12 must remain independent, a clean checkout must use the tracked CC0 starter, and no local source or derivative may be distributed.
- When runtime-checking in Max, save intentional patch edits, close every patcher and Project window opened by the task, and quit the task-owned Max instance before reporting completion.
- Treat `assets/asset_manifest.json` and `ASSET_LICENSES.md` as the provenance authority for distributable assets. Distributable runtime field recordings must remain CC0/CC BY, hash-verified, DC-cleaned, faded, and normalized. User-supplied local-only references must be deterministically processed, hash-reported, ignored by Git, and never synced or redistributed.
- Preserve every sibling V1/V2/V3/V4 repository. V4 is frozen at tag `v4.0.0`; all new implementation work belongs in this V6 repository.
